# A Biblioteca Infinita: site

Site do jogo educativo **A Biblioteca Infinita**, para crianças de 6 a 10 anos com dislexia (protótipo em desenvolvimento, ainda sem teste com crianças).

- `index.html`: a página inteira (HTML, CSS e JS). Abra no navegador para ver.
- `img/`: capturas do protótipo (arte provisória, perfil fictício).
- `fonts/`: OpenDyslexic (Bitstream Vera License). Baloo 2 e Lexend vêm do Google Fonts (SIL OFL).

Este repositório só tem o site. O código do jogo fica em outro repositório, privado.

Para atualizar, edite `index.html` e faça commit em `main`; o GitHub Pages republica sozinho (Settings ▸ Pages ▸ Deploy from a branch ▸ `main` ▸ `/ (root)`).
